Offline Video App
=================
This project downloads direct video-file URLs (such as authorized MP4/WebM files) and stores them in IndexedDB for offline playback.

Run:
- Open the folder in VS Code.
- Use a local server/Live Server rather than file://.
- Paste a direct video URL and press Download.

Important:
- The browser requires the video server to allow cross-origin requests (CORS), otherwise the download can fail.
- This project does not bypass YouTube downloading restrictions.
